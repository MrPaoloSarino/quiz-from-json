# UI/UX Excellence Rules

## Accessibility Rules
- ALWAYS use semantic HTML elements
- ALWAYS provide proper ARIA labels and descriptions
- ALWAYS ensure proper color contrast ratios
- ALWAYS implement keyboard navigation support
- ALWAYS provide alternative text for images
- ALWAYS use proper heading hierarchy
- ALWAYS implement focus management properly

## Responsive Design Rules
- ALWAYS use mobile-first design approach
- ALWAYS implement proper breakpoints
- ALWAYS ensure touch-friendly interface elements
- ALWAYS optimize for different screen sizes
- ALWAYS use flexible layouts and grids
- ALWAYS implement proper viewport handling
- ALWAYS test on multiple devices and orientations

## Loading States Rules
- ALWAYS provide immediate feedback for user actions
- ALWAYS use skeleton screens for content loading
- ALWAYS implement proper loading indicators
- ALWAYS show progress for long-running operations
- ALWAYS provide optimistic UI updates
- ALWAYS handle loading failures gracefully
- ALWAYS use consistent loading patterns

## Quiz-Specific UI Rules
- ALWAYS provide clear question presentation
- ALWAYS implement intuitive answer selection interface
- ALWAYS show progress indicators during quizzes
- ALWAYS provide immediate feedback for answers
- ALWAYS implement smooth transitions between questions
- ALWAYS provide clear navigation controls
- ALWAYS implement proper quiz completion flows

## Visual Design Rules
- ALWAYS use consistent color schemes and typography
- ALWAYS implement proper spacing and alignment
- ALWAYS use visual hierarchy effectively
- ALWAYS provide clear visual feedback for interactions
- ALWAYS use appropriate icons and visual elements
- ALWAYS implement proper dark/light mode support
- ALWAYS ensure visual consistency across components

## Interaction Design Rules
- ALWAYS provide clear call-to-action buttons
- ALWAYS implement proper hover and focus states
- ALWAYS provide confirmation for destructive actions
- ALWAYS implement proper form validation feedback
- ALWAYS provide clear error messages
- ALWAYS implement proper success feedback
- ALWAYS use appropriate animation and transitions

## User Experience Rules
- ALWAYS minimize cognitive load
- ALWAYS provide clear navigation paths
- ALWAYS implement proper onboarding flows
- ALWAYS provide helpful tooltips and guidance
- ALWAYS implement proper search and filtering
- ALWAYS provide clear data visualization
- ALWAYS implement proper data entry validation

## Performance UI Rules
- ALWAYS optimize for perceived performance
- ALWAYS implement proper lazy loading
- ALWAYS use efficient rendering techniques
- ALWAYS optimize images and media
- ALWAYS implement proper caching strategies
- ALWAYS minimize layout shifts
- ALWAYS optimize for Core Web Vitals
