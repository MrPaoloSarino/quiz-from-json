# 🤖 Simple AI Guide - How to Use AI Features

## 🎯 **Your Ideal Setup - Now Working!**

### **Step 1: Add Your API Key** ⚙️
1. Go to **Settings** (gear icon in top right)
2. Choose **AI Settings** tab
3. Pick your provider (OpenRouter, Gemini, or OpenAI)
4. Paste your API key and click **Save**
5. ✅ **That's it!** The system will automatically detect and use your key

### **Step 2: Take a Quiz** 📝
1. Create or start any quiz
2. Answer questions normally
3. After submitting an answer, you'll see the **AI Explainer** section

### **Step 3: Get AI Explanations** 🧠
1. Click **"Get Explanation"** button
2. AI automatically analyzes:
   - ✅ Your answer
   - ✅ The correct answer  
   - ✅ The original question
   - ✅ Whether you got it right or wrong
3. Get a detailed, personalized explanation!

### **Step 4: Chat with AI** 💬
1. After getting an explanation, click **"Ask Questions"**
2. The AI remembers everything about the question
3. Ask follow-up questions like:
   - "Why is my answer wrong?"
   - "Can you explain this concept more?"
   - "What should I study next?"
   - "Give me a similar example"

## 🐛 **Troubleshooting**

### **"AI explanations are not available"**
- Go to Settings → AI Settings
- Add any valid API key
- System will auto-activate

### **"No AI provider configured"**
- Check your API key is saved (should show "✅ Saved")
- Try clicking "Test" to verify the key works
- Make sure you have internet connection

### **"Failed to generate explanation"**
- Check your API key hasn't expired
- Verify you have quota/credits remaining
- Try a different provider if one isn't working
